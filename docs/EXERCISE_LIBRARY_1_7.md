# Библиотека упражнений · Windows 1.7.0

Изменения согласованы владельцем после просмотра всех 190 иллюстраций. Подготовлен локальный установщик Windows x64. Публикация и проверка установки на физическом Windows-ПК отдельно.

## Что изменилось

«Тренировки → Инвентарь → Библиотека упражнений» открывает самостоятельную библиотеку. Тот же выбор работает в силовой тренировке и для отдельного упражнения ОФП.

- Основная подборка: 190 вариантов, 78 групп движений. Группа открывает конкретные варианты, а не заменяет их одним упражнением.
- Расширенный выбор: 310 вариантов суммарно. Полный прежний каталог доступен отдельной настройкой выбора; ничего не удалено.
- Поиск учитывает прежние названия и синонимы. Фильтры: мышцы, инвентарь, назначение. ОФП — назначение той же записи, без отдельной копии упражнения.
- Недавние, избранные, собственные упражнения. Избранное хранится в зашифрованной базе в настройке `exercise_favorites`.
- 190 оригинальных PNG включены в приложение для работы без интернета. Это статические изображения ключевых положений; они не обрезаются под старые фотоспрайты и не переключаются таймером.
- Свой вариант можно добавить/изменить без комплекса: название, инвентарь, категории, основные и дополнительные мышцы, описание, учёт повторов/секунд/контактов, стороны, локальная картинка или GIF до 2 МБ.

## Сохранность данных

Все 924 прежних ID, описания, коэффициенты веса тела, анатомические поля и старые фотографии остаются на месте. Добавлены 14 новых стабильных ID с префиксом `new_`; история не переназначается между вариантами. Новое представление каталога применяется только в библиотеке, силовых и отдельных упражнениях ОФП. Блоки с ID персонального комплекса и его редактор получают прежние названия и медиа.

Отдельная команда `exercise_custom_save` обновляет одну запись `custom_exercises`; она не пишет `complexes` или подходы тренировок. Прежний редактор сохраняет дополнительные поля упражнения и записи, добавленные через библиотеку, пока редактор был открыт. Если пользователь меняет в нём флажки времени или выполнения по сторонам, новые метаданные согласуются с этим выбором. Повреждённая настройка собственных упражнений вызывает ошибку сохранения и не заменяется пустым списком. Миграция и преобразование личной базы для этой версии не нужны.

## Границы

Новые мышцы не превращаются в точные проценты нагрузки. Для стопы и сгибателей бедра карточка сообщает об ограничениях нынешней карты мышц. Новым движениям не присваиваются выдуманные коэффициенты веса тела. У переноса гири в этой версии записывается время на сторону; отдельное поле метров не добавлено. Контакты сохраняются в существующем счётчике повторений с подписью «контакты». Все силовые расчёты используют прежнюю модель. В упражнении на каждую сторону вес вводится на одну сторону, при одновременной работе обеих — суммарный вес снарядов.

Турецкий подъём — четыре опорных положения с отдельной подписью: переходы и спуск не показаны. Дополнительные 120 вариантов расширенного выбора пока используют прежние изображения. Независимая проверка техники каждой иллюстрации тренером не проводилась.

## Проверки

- `npm run build` — TypeScript и production-сборка интерфейса.
- `python tools/exercises/validate_catalog.py` — ID, подборки, ссылки, 190 SHA256 оригинальных PNG, 78 групп, прежние ОФП/ленты и версия Windows.
- `cargo test --manifest-path tools/exercise-tests/Cargo.toml -- --test-threads=1` — production-код exercise_svc на временных SQLite-базах: сохранность истории, комплексов, коэффициентов и метаданных, избранное и отклонение неверного ввода. Последовательный запуск нужен из-за общего кеша CUSTOM сервиса.
- При запущенном Vite: `python tools/tests/exercise_library.py --url http://127.0.0.1:5173` — браузерные сценарии на вымышленных данных; проверяет также выбор для силовой/ОФП и прежнее представление комплексов. Нужны Python Playwright и Chromium.

Нативная проверка Windows и пробное обновление существующей установки обязательны перед выпуском установщика. Секреты и личная база в проверках не используются.
