# Kouros

![Windows](https://img.shields.io/badge/Windows-10%20%7C%2011-0078D6) ![Tauri](https://img.shields.io/badge/Tauri-2-24C8DB) ![Rust](https://img.shields.io/badge/Rust-engine-B7410E) ![Язык](https://img.shields.io/badge/интерфейс-русский-3DDC97)

**Личный тренер и дневник здоровья для бегуна — на твоём компьютере.**

Kouros собирает в одном месте тренировки, сон, пульс, HRV, питание, витамины и самочувствие, сам считает нагрузку, готовность и восстановление и каждый день подсказывает, сколько и как тренироваться. Данные хранятся только у тебя на компьютере, в зашифрованной базе.

Интерфейс на русском. Работает на Windows 10/11.

> [!IMPORTANT]
> Kouros — **не медицинское изделие**. Он не ставит диагнозов и не заменяет врача или тренера: все советы о здоровье и лекарствах сводятся к «обрати внимание» и «обсуди с врачом».

> [!NOTE]
> Это личный проект, а не официальное приложение Strava, Apple, Garmin, freddy или производителей добавок. Каталог добавок собран из открытых источников и может отличаться от этикетки твоей банки — Kouros всегда просит сверить состав.

## ✨ Что умеет

**☀️ Сегодня**
- Готовность утром и вечером (0–100) — относительно *твоей* нормы за 30 дней: HRV и пульс покоя за ночь, сон, дыхание, температура, нагрузка.
- План дня по готовности: интервалы, темп, аэробная, лёгкая, восстановительная или отдых — с объёмом в минутах и нагрузке.
- Риск травмы (соотношение острой и хронической нагрузки — отдельно для сердца и для мышц и связок), восстановление в часах, стресс за день.
- Сон: потребность, долг, план на ночь.

**🏃 Тренировки**
- Загрузка из Strava (и/или Apple Health, Garmin, Suunto через freddy), импорт файлов FIT/GPX/TCX и архива Strava.
- Нагрузка по TRIMP, форма и усталость (CTL/ATL/TSB), зоны пульса и темпа, рекорды и прогнозы на дистанции, обувь и её пробег.
- Отдельная нагрузка на мышцы и связки (подъёмы, спуски, скорость, силовые по группам мышц) и карта мышц.
- Страница тренировки: графики, карта маршрута (OpenStreetMap, по желанию), сплиты, зоны, подходы силовых, RPE.

**💤 Здоровье**
- Гипнограмма сна, ночные HRV / пульс / SpO₂, коридоры нормы, ранние сигналы болезни.
- Привычки и их влияние на HRV следующего утра, алкоголь, кофеин.
- Витамины и лекарства: каталог добавок (Maxler, NOW, Solgar), поиск в базе NIH, реестр лекарств РФ, верхние безопасные пределы, время приёма и сочетания, группы лекарств, важные для спорта, личный эффект.

**🥗 Питание** — цели по калориям, БЖУ и клетчатке под тренировки и цель по весу, 22 витамина и минерала с нормами разных стран, оценка недостающих данных по продуктам.

**🧠 Психология** — опросники Hooper, TQR, BRUMS и свой короткий опрос стресса и восстановления.

**🎯 Тренер**
- Знакомство, «Как мой день?», анализ недели, план тренировок на неделю с блоками и разгрузкой, предложения замен, когда готовность или боль не позволяют.
- Дневник боли на фигуре, возврат к бегу после травмы, цель и контрольные тесты.
- «Спросить Claude»: Kouros готовит сводку, ты вставляешь её в свой чат с Claude, а ответ (в том числе изменения плана) — обратно.

## ⚙️ Как это работает

```
Strava ─┐                      ┌─ движок расчётов (Rust) ─┐
freddy ─┼─► Kouros на ПК ─────►│  нагрузка, готовность,   ├─► экраны
файлы  ─┘   (SQLCipher-база)   │  сон, питание, план      │
                               └──────────────────────────┘
```

- **Цифры считает код**, а не ИИ: формулы лежат в `src-tauri/src/engine/` и сервисах рядом.
- **Здоровье и питание** приходят через [freddy](https://freddy.coach) — сервис, который собирает Apple Health, Garmin, Suunto, Fitbit и другие источники. Для каждого вида данных можно выбрать свой источник.
- **Наружу** Kouros обращается только к Strava, freddy, по желанию — к картам OpenStreetMap и к открытым базам (NIH — добавки и группы лекарств, grls.rosminzdrav.ru — реестр лекарств). Уходит только то, что нужно для запроса, — никаких личных данных. Аналитики нет.

## 📦 Установка

1. Открой **Releases** справа и скачай `Kouros_<версия>_x64-setup.exe`.
2. Запусти установщик. У программы нет цифровой подписи, поэтому Windows может показать «Windows защитил ваш компьютер» → **Подробнее → Выполнить в любом случае**.
3. Новые версии ставятся поверх старых — данные сохраняются.

## 🚀 Первый запуск

1. **Профиль** (Настройки → Профиль и зоны): имя, год рождения, рост, пол, максимальный пульс, пороговый темп. Пока профиль не заполнен, Kouros считает по общим формулам и показывает напоминание на «Сегодня». Если есть результаты лабораторного теста — бери пульсовые зоны и порог оттуда.
2. **Strava** (Настройки → Синхронизация): создай своё приложение на [strava.com/settings/api](https://www.strava.com/settings/api) (Authorization Callback Domain — `127.0.0.1`), впиши Client ID и Client Secret в Kouros и нажми «Подключить».
3. **freddy** (по желанию, для сна, пульса, HRV, питания): подключи свои устройства на [freddy.coach](https://freddy.coach), создай API-ключ и впиши его в Kouros.
4. **Тренер** → знакомство: цели, режим, травмы, чем восстанавливаешься. Из этого строится план недели.

Ключи вводятся только в самом приложении и хранятся в Диспетчере учётных данных Windows — не в файлах и не в коде.

## 🔒 Где лежат данные

`C:\Users\<имя>\Kouros\`

| Что | Где |
| --- | --- |
| База (вся история, SQLCipher, AES-256) | `kouros.db` |
| Импортированные файлы | `files\` |
| Резервные копии (раз в день, последние 14) | `backups\` |
| Выгрузки | `exports\` |

Ключ базы хранится в Диспетчере учётных данных Windows. Для переноса на другой компьютер нужен ключ восстановления: Настройки → Данные и безопасность. Можно включить вход по Windows Hello.

## 🛠 Для разработчиков

- Интерфейс: React 18 + TypeScript + Vite (`src/`). `npm run dev` открывает его в браузере на демо-данных.
- Приложение: Tauri 2 на Rust (`src-tauri/`), база SQLCipher, миграции в `db.rs`.
- Формулы — в `src-tauri/src/engine/` (без внешних библиотек).
- Каталог добавок и реестр лекарств собирает `tools/catalog/build.py` (GitHub Actions → `src-tauri/resources/`).
- Сборка: push в любую ветку — проверка (`check.yml`), push в `main` — установщик в Releases (`build.yml`).

Локально (Node 22, Rust, WebView2):

```
npm install
npm run tauri dev
```
